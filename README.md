# Agente de Copywriting & Páginas de Conversão (`skill-copywriting-ai-cowork`)

> Skill oficial distribuída pela **AI Cowork Academy** para empresários e gestores estruturarem **Copywriting & Conversão** com Agentes de IA.

## O que este agente faz

Escreve headlines, páginas de vendas, anúncios e e-mails baseados na linguagem real do cliente e em provas concretas.

## Como instalar em 1 comando

Copie e cole este prompt direto na sua IA (Claude Code, Codex, ChatGPT ou Antigravity):

```text
Acesse o repositório https://github.com/nitroxinteligence/skill-copywriting-ai-cowork, leia o arquivo SKILL.md completo (e a pasta references/) e instale esta skill no meu workspace para eu usar agora.
```

## Como utilizar na prática

Descreva seu produto, quem compra e as 3 dúvidas mais comuns no comercial. O agente entrega a copy estruturada por blocos, sem clichês e pronta para publicar.
